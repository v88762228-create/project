ИНФОРМАЦИОННАЯ СИСТЕМА УПРАВЛЕНИЯ ЗАДАЧАМИ

ОБЩЕЕ ОПИСАНИЕ
Данный проект представляет собой консольное приложение на языке Python 3, предназначенное для управления задачами пользователей.
Система позволяет:
управлять задачами
управлять пользователями
назначать статусы задач
назначать приоритеты
добавлять комментарии
В качестве базы данных используется SQLite, что позволяет хранить данные в одном файле без установки дополнительных СУБД.

СТРУКТУРА ПРОЕКТА
Проект состоит из следующих файлов и папок:
config.py Содержит имя базы данных.
main.py Главный файл запуска программы.
database/db_manager.py Модуль для создания базы данных и подключения к ней.
models/ Содержит классы моделей:
task.py – работа с задачами
user.py – работа с пользователями
comment.py – работа с комментариями
status.py – работа со статусами задач
priority.py – работа с приоритетами
ui/ Содержит пользовательский интерфейс:
menu.py – главное меню
menu_tasks.py – управление задачами
menu_users.py – управление пользователями
menu_comments.py – управление комментариями
menu_statuses.py – управление статусами
menu_priorities.py – управление приоритетами

ФУНКЦИОНАЛ СИСТЕМЫ
Система позволяет:
добавлять задачи
редактировать задачи
удалять задачи
просматривать список задач
добавлять пользователей
просматривать пользователей
назначать статусы задач
назначать приоритеты задач
добавлять комментарии к задачам

БАЗА ДАННЫХ
В системе используются следующие таблицы:
roles – роли пользователей
users – пользователи
tasks – задачи
comments – комментарии
task_status – статусы задач
priorities – приоритеты задач
Связи между таблицами реализованы через внешние ключи (FOREIGN KEY).

ПРИНЦИП РАБОТЫ
При запуске программы выполняется функция initialize_db(), которая:
создает таблицы, если они отсутствуют
подготавливает базу данных к работе
Далее пользователю отображается главное меню, через которое он может управлять системой.

ТРЕБОВАНИЯ
Для запуска программы необходимо:
Python 3.10+
стандартные библиотеки Python (sqlite3)

ЗАПУСК ПРОГРАММЫ
Запуск осуществляется командой:
python main.py
